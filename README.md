Chivvy is a real-world, GPS-based hide-and-seek game for small groups, played in the browser on Android Chrome. The hunted get a head start inside a shared play area, then the hunters chase them, guided by colored compass arrows. Arrows appear only while the hunter stands still. A hunter catches someone by getting close enough. Players who leave the area or lose GPS are out. After the game, everyone sees all players’ routes on a map.

Built as a single static index.html (no build step), hosted on GitHub Pages, using Firebase Realtime Database and anonymous auth for sync. Players join by QR code or game code.
